# cocoa

COCOA(COntent COmmercialization Optimization Agent)는 제휴 상품과 노출 위치를
고르는 Contextual Bandit 에이전트다. 지연·취소되는 제휴 수수료 보상을 공개
데이터(Open Bandit Dataset, Criteo Attribution Dataset)만으로 학습·평가하는
대학원 연구 프로젝트다.

- 아키텍처 설계: [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md)
